# Supabase

- `migrations/`: 리뷰 가능한 SQL 스키마 변경 이력. 실제 CLI 초기화 후 생성되는 파일 이름 규칙을 따릅니다.
- `tests/`: DB 권한·RLS 등 DB 관련 검증.

아직 Supabase CLI 초기화나 원격 프로젝트 연결은 하지 않았습니다. 초기화 후 생성된 비밀 정보 없는 설정 파일은 커밋하고, 인증 토큰·DB 비밀번호는 커밋하지 않습니다.

스키마 변경은 이 디렉터리를 기준으로 관리합니다. 백엔드에 별도 Flyway 이력을 동시에 만들지 않습니다. 이미 적용한 마이그레이션을 수정하지 않고 새 변경 파일을 추가합니다. 원격 DB 적용 전에는 별도의 개발 환경에서 확인합니다.
